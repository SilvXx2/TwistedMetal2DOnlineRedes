JUEGOS EN RED - RESUMEN ORDENADO

1. Conceptos de Red

Ancho de Banda

Cantidad máxima de datos que se pueden transmitir por segundo (bps /
Mbps). Analogía: autopista (cantidad de carriles).

Tick Rate

Frecuencia de actualización de la simulación (ej: 30Hz, 60Hz).

Send Rate

Frecuencia de envío de paquetes desde el cliente.

IMPORTANTE: Optimizar qué datos se envían y con qué frecuencia para
evitar saturación.

------------------------------------------------------------------------

2. Flujo de Paquetes

1.  Input del jugador (input lag)
2.  Juego empaqueta evento
3.  SO agrega headers (IP, UDP, Photon)
4.  Viaje por red (puede haber pérdida)
5.  Llega al receptor y se procesa

------------------------------------------------------------------------

3. Latencia y Lag

Latencia

Tiempo de ida de un paquete.

RTT (Round Trip Time)

Tiempo de ida y vuelta.

Lag

Percepción del usuario (no es métrica directa).

OBJETIVO: Ocultar o mitigar el lag.

------------------------------------------------------------------------

5. Network Simulator

Permite simular: - Lag - Pérdida de paquetes - Jitter

true;

------------------------------------------------------------------------

6. Trilema del Netcode

No se puede tener todo: - Consistencia perfecta - Respuesta
instantánea - Bajo uso de red

Siempre hay trade-offs.

------------------------------------------------------------------------

7. Interpolación

Suaviza movimientos pasados (evita saltos).

Ejemplo típico:

void Update() { if (!photonView.IsMine) { transform.position =
Vector3.Lerp( transform.position, networkPosition, Time.deltaTime *
smoothSpeed ); } }

------------------------------------------------------------------------

8. Extrapolación

Predice posiciones futuras usando velocidad.

Ejemplo:

void Update() { if (!photonView.IsMine) { float lag =
PhotonNetwork.Time - lastUpdateTime; Vector3 predictedPosition =
networkPosition + velocity * lag; transform.position =
predictedPosition; } }

------------------------------------------------------------------------
